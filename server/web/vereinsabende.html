Kasse / Teilnehmer / Scheiben / Wertungen verwalten →

Verkauf, Guthaben, Teilnehmerverwaltung und Wertungen werden über die gemeinsame Preisschießen-Oberfläche gepflegt (identische Mechanik, nur andere Auswertelogik).

Saison-Einstellungen

Nur Scheiben, deren tatsächlicher Schießtag auf einen dieser Wochentage fällt, gehen in die Jahreswertung ein.

Abweichender Wochentag

Scheiben, deren tatsächlicher Schießtag nicht auf einen der Saison-Wochentage fällt - hier können sie per "Vor-/Nachschuss markieren" einem korrekten Datum zugeordnet werden (die Anwesenheit zählt dann für diesen Tag nicht), oder einfach ignoriert werden (sie fließen dann weiterhin nicht in die Jahreswertung ein).

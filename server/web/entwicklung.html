Entwicklung

Testdaten generieren

Legt neue Mitglieder mit Nachname "Testuser" an (Vorname zufällig, verteilt auf bestehende Vereine), meldet einen Teil davon im gewählten Preisschießen an, kauft je Teilnehmer ein zur ermittelten Altersklasse passendes Set plus einige zusätzliche Einzelscheiben desselben Typs und beschießt jede gekaufte Scheibe vollständig mit Zufallswerten zwischen 6,0 und 10,9 (inkl. dazu passendem Teiler/Ring). Kann beliebig oft wiederholt werden.

Testdaten löschen

Entfernt ALLE jemals mit diesem Werkzeug erzeugten Testuser-Mitglieder samt Anmeldungen, Käufen, Buchungen und Sessions - über alle Preisschießen hinweg, unwiderruflich. Vor dem Löschen wird automatisch ein Sicherheits-Backup angelegt. Echte Mitglieder sind davon nicht betroffen.

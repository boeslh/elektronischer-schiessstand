Teilnehmende Vereine

Nur ausgewählte Vereine erscheinen in den Vereins-Auswertungen (Tab "Auswertung"). Ein Verein kann als Gastgeber markiert werden - dieser belegt dort unabhängig von seinen Werten immer den letzten Platz.

Punkte-Zeiträume

Für die Auswertung "Teilnehmer Punkte": jedem Teilnehmer werden anhand des Datums seines ersten Schusses in diesem Preisschießen (erste Scheibe begonnen oder beendet) die Punkte des passenden Zeitraums gutgeschrieben, je Verein aufsummiert. Höchstens 5 Zeiträume, Datum außerhalb aller Zeiträume zählt 0 Punkte.

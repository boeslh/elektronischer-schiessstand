StandPC-Verbindungen

HTTP-Basis-URL jedes StandPC (z.B. http://192.168.1.10:8080). Wird für Standaktionen verwendet: Schüsse aus lokalem Log abrufen, Disziplinen übertragen.

Wenn der StandPC mit server_url konfiguriert ist, meldet er sich automatisch beim Server an – die URL wird dann beim nächsten Heartbeat eingetragen.

Wettkampf-Vorgaben (Schießzeit)

Vorbelegung für neue Wettkämpfe – im Wettkampf selbst jederzeit änderbar. Die Zeiten kommen aus der Disziplin (Gesamtzeit oder getrennte Probe-/Wertungszeit).

Bei einer Gesamtzeit für Probe und Wertung schaltet immer jeder Schütze selbst um.

Online-Veröffentlichung (Internet)

Preisschießen und Rundenwettkämpfe auf einem Online-Server im Internet anzeigen. Die Verbindung baut dieser Server selbst auf (verschlüsselt per HTTPS, angemeldet mit dem API-Schlüssel des Vereins). Übertragen werden nur die Anzeigedaten: Startnummer, Name und Verein der Teilnehmer mit Ergebnissen bzw. die Starter eines Rundenwettkampfs mit Ergebnissen und Treffern – keine Stammdaten.

Der Schlüssel wird auf dem Online-Server in der Verwaltung erzeugt.

Entwicklermodus

Nur zu Testzwecken: ist der Modus aktiv, kann am Stand-PC direkt auf die Zielscheibe geklickt werden, um einen Schuss an dieser Position auszulösen – ohne echte Sensor-Hardware. Gilt sofort für alle Stände.

Schriftgrößen (Stand-PC)

Gilt für die Anzeige an jedem Stand-PC, getrennt nach Bereich. Bei "Ergebnisse" betrifft der Wert die Einzelschuss-Zeilen; Gesamt, Serien und der große Einzelschuss-Wert ganz oben bleiben automatisch im gleichen Abstand größer wie bisher.

Admin-Passwort (Stand-PC)

Schützt die lokale Admin-Oberfläche jedes Stand-PC (/admin), über die Kalibrierung und Konfigurationsparameter direkt am Stand geändert werden können. Nur der Hash wird gespeichert und an alle Stände verteilt – das Passwort selbst wird hier nicht angezeigt.

Ergebnis-Ausgabe am Stand (E-Mail / Drucker)

Am Stand-PC kann sich der Schütze über „📤 Ergebnis“ sein Einzelergebnis als PDF per E-Mail (an die in den Stammdaten hinterlegte Adresse) schicken oder ausdrucken lassen. Der QR-Code für die App ist immer verfügbar. E-Mail bzw. Druck werden am Stand nur angeboten, wenn sie hier eingerichtet sind.

Papierscheiben (Seriennummer / Etikett)

Beim Verkauf einer Papierscheibe im Preisschießen wird eine Seriennummer vergeben. Über den Etikettendrucker (Datamax, Etikett 45 × 30 mm) lässt sich in der Kasse je Papierscheibe ein Etikett mit Barcode, Scheibenname, Seriennummer, Teilnehmernummer und Name drucken.

Fortlaufend: keine Eingabe beim Verkauf; bereits vergebene Nummern werden übersprungen.
CUPS-Warteschlange im Rohdaten-Modus (DPL).
Etikettendrucker einrichten (Beispielbefehle)

Der Etikettendrucker (z. B. Datamax E-4203) wird auf dem Schießstand-Server in CUPS als Warteschlange ohne Treiber angelegt – der Server schickt die DPL-Daten unverändert („raw“). Die Befehle in einem Terminal auf dem Server ausführen; der Name Etiketten ist frei wählbar. Läuft der Server in einer virtuellen Maschine, muss die Schnittstelle (bzw. der USB-Adapter) an die VM durchgereicht werden.

Drucker am Parallelport

# Treiber für den Parallelport laden
sudo modprobe lp ppdev parport_pc
# Gerätedatei prüfen (erwartet: /dev/lp0)
ls -l /dev/lp*
# Warteschlange ohne Treiber anlegen
sudo lpadmin -p Etiketten -E -v parallel:/dev/lp0

Drucker über USB2Parallel-Adapter

# Adapter muss in der Liste erscheinen
lsusb
# Gerätedatei prüfen (erwartet: /dev/usb/lp0)
ls -l /dev/usb/lp*
# CUPS-Adresse des Adapters ermitteln (z. B. usb://...)
sudo lpinfo -v | grep -i usb
# Warteschlange ohne Treiber anlegen, Adresse aus lpinfo einsetzen
sudo lpadmin -p Etiketten -E -v 'usb://…'

Findet lpinfo keine usb://-Adresse, geht auch direkt die Gerätedatei: sudo lpadmin -p Etiketten -E -v parallel:/dev/usb/lp0

Prüfen

# Warteschlange und Anschluss anzeigen
lpstat -v Etiketten
# Etikett mit „TEST“ drucken
printf '\002L\rD11\r1211000002000200TEST\rE\r' | lp -d Etiketten -o raw

Kommt das Test-Etikett, diese Seite neu laden, oben Etiketten als Etikettendrucker wählen, speichern und Testetikett drucken. Ein Hinweis von lpadmin, dass Warteschlangen ohne Treiber veraltet sind, kann ignoriert werden.
